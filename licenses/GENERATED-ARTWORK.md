# Original generated game artwork

The fictional adult footballer's reference sheet in src/assets/fictional-player-reference.png was generated for this project with the built-in image_gen tool on 2026-09-22. No real person's reference photograph was submitted. It is not a licensed image of a real footballer or an EA/Nexon asset. The game projects this original sheet to src/assets/default-face.jpg. The prompt and conversion workflow are recorded in reports/FACE-ON.md in the source package.
