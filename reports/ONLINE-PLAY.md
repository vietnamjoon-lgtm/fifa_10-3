# 친구 대전과 조작 지원

게임 주소: https://project-touchline-three.vercel.app/

## 친구와 경기하기

1. `친구와 1대1` → 이름 입력 → `새 방 만들기`.
2. 표시된 초대 링크 또는 8자리 방 코드를 친구에게 보냅니다.
3. 친구가 링크에서 입장하고, 두 사람 모두 `준비 완료`를 누릅니다.
4. 방장이 `경기 시작`을 누르면 홈과 원정 팀을 각각 조작합니다.

브라우저 두 개가 같은 공·선수·점수를 받습니다. 서버가 물리와 판정을 계산하고 클라이언트는 입력만 전송합니다. 연결이 끊기면 경기를 멈추고 45초 동안 재접속을 기다립니다. 경기 중 메뉴만 열면 상대의 경기는 계속됩니다. 서버 재시작·재배포 후에는 기존 방을 복구하지 못하므로 새 방을 만들어야 합니다.

## 기본 조작 지원

`킥오프`의 매치 센터에서 바꿀 수 있으며 친구 대전에도 각자의 설정이 적용됩니다. `쾌적한 조작 추천 설정 적용`으로 아래 값을 복원합니다.

| 설정 | 기본값 |
|---|---|
| 선수 자동 전환 | 공중볼만 |
| 전환 방향 유지 | 없음 |
| 패스 / 스루·로빙 스루 | 자동 |
| 크로스 | 중간 |
| 아날로그 스프린트 | 끄기; 패드는 선택적으로 켜기 |
| 수비 방향 지원 | 켜기 |
| 침투 방향 | 3 · 빈 공간 찾기 |

패스 후에는 수신할 선수의 커서를 0.85초 보호합니다. 잠깐 다른 동료가 공에 닿아도 즉시 커서를 빼앗지 않습니다. 수동 전환은 자동 전환보다 우선하며 0.7초 보호됩니다. 기본 공중볼 모드에서는 지상 수비 커서를 임의로 바꾸지 않습니다. 공격 시 실제 소유자가 바뀌면 안정된 소유를 확인한 뒤 조작 선수를 갱신합니다. `전환 방향 유지 없음`은 이전 입력의 강제 유지를 없애며 선수의 물리적 가감속까지 제거하지는 않습니다.

중간 크로스는 수신 선수 위치와 사용자의 방향을 섞습니다. 키보드 E는 아날로그 설정과 무관하게 항상 전력 질주 입력을 보냅니다. 패드는 옵션을 켠 경우 트리거 깊이를 속도에 반영합니다. 침투 타입 3은 주변 수비수로부터 떨어진 전방 공간을 선택합니다. 이 번호와 보정은 이 게임의 자체 구현이며 FC Online의 비공개 알고리즘과 동일하다는 의미는 아닙니다.

## 애니메이션

달리기와 축구 킥에는 [CMU Graphics Lab Motion Capture Database](https://mocap.cs.cmu.edu/)의 09_01, 10_01을 사용합니다. 원본 관절 운동을 선수 비율에 맞추고, 킥 순간 발 위치를 공에 맞추는 보정을 섞었습니다. 자료와 이용 근거는 `licenses/CMU-MOCAP.txt`에 있습니다.

`동작 자세히 보기`에서 각도, 재생 속도, 동작 구간을 조절할 수 있습니다. 헤딩·슬라이딩·태클·다이빙 등의 특수 동작은 자체 제작 방식입니다. 현재 선수 메시, 모션 전환, 발 접지는 상용 FC 시리즈와 같은 수준이 아니며 원작과 동일한 애니메이션을 재현했다고 주장하지 않습니다.

## 서버와 검증

Cloudflare Worker: https://project-touchline-arena.project-touchline.workers.dev

방마다 Durable Object 하나, 고정 물리 120Hz, 서버 루프 60Hz, 상태 전송 25Hz, 입력 전송 30Hz입니다. 클라이언트는 상태를 약 65ms 지연 보간합니다. 무료 플랜으로 배포하며 실제 지연은 접속 지역과 회선에 따라 달라집니다.

79개 자동 검사는 두 사람의 독립 조작, 서버 상태 일치, 재접속, 입력 검증, 패스 커서 유지, 자동 전환, 보정 방향, 모션 좌표를 포함합니다. `reports/online-live-check.json`은 실제 배포 서버에 두 WebSocket 클라이언트를 연결한 결과입니다. 물리 게임패드 실기기 검증은 아직 하지 않았습니다.
