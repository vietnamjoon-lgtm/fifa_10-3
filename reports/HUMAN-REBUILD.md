# 사람형 선수 리빌드 — 구현 및 검증 현황

기준 리비전: 4a8f1426e8e221260e800ee89fd4284e8b634f7e. 기존 경기/친구 작업을 유지한 검토용 변경이다. 문서 전체의 완료 판정이 아니며, 아래 미달·미검증 항목을 남긴다. 작업 브랜치에서 검토하며, main 병합·배포는 포함하지 않는다.

## 적용한 내용

- 체형은 마름·보통·건장·고유 4종이다. 고유는 개별 비율을 유지한다. 기존 선수 저장값·얼굴 사진 참조·키·몸무게·16개 체형 슬라이더를 보존한다.
- 기존 13개 애니메이션 제어 관절을 유지하면서, 원본 부모 관계가 있는 74개 변형 관절을 추가했다. 척추 5개, 목 3개, 팔/다리 비틀림, 손목과 30개 손가락 관절을 포함한다.
- 중립 체형은 두상 메시 높이로 약 7.91등신이다. 중립 체형의 위팔/아래팔/허벅지/종아리 길이를 각각 키의 0.186/0.146/0.245/0.246으로 맞췄다. 어깨/고관절/무릎 높이는 0.818/0.530/0.285이다. 사용자 문서의 기준값이며 모든 실제 사람에게 동일하다는 뜻은 아니다.
- 근거리 DQS, 원거리 13관절 LBS, 무릎·팔꿈치·골반·어깨 보정 모양, 분리된 유니폼 표면, 스터드·밑창·앞꿈치 관절이 있는 축구화를 적용했다. 유니폼은 천 시뮬레이션이 아니다.
- CMU 걷기·조깅·방향 전환·정지 캡처를 추가했다. 달리기 접지 판정에서 수평 속도가 빠진 원인을 수정했다.
- 발의 지지/이륙 전환, 닿을 수 있는 범위의 조기 이륙, 착지 속도가 이어지는 궤적, 골반 보정 누적 오류를 수정했다. 경기의 속도·가속·공 물리·드리블 터치 규칙은 변경하지 않았다.
- 무게중심 추정치와 무릎·팔꿈치 회전 범위 진단을 추가했다. 시뮬레이션에 힘을 적용하거나 위반 각도를 잘라 숨기지 않는다.
- 실제 게임 모델 비교 화면은 src/human-review.html이다. 정면/측면/후면/위, 동작 선택, 프레임 단위 보기, 실제 캔버스 이미지 저장을 제공한다. 예시 선수는 가상 인물이다.

## 측정 방법과 결과

수치 원본: human-baseline.json, human-motion-after.json, human-subframe.json, human-skin.json, human-performance.json. 자동 요약표는 아래에 기록한다.

- 경기 120Hz / 관절 960Hz, 12초씩 20개 시나리오: 양 팀, 조깅/질주, 45·90·180도 전환, 난수 시드 17/43/97/113. 매번 새로운 경기와 제어 뼈대를 사용한다. 동일 시나리오 반복 결과의 재현성도 확인했다.
- 미세 샘플 검사는 실제 경기 한 스텝을 5,000분할한 발 목표 궤적 240건이다. 전체 경기의 렌더된 메시를 5,000배 샘플링한 검사는 아니다.
- 관절 단면 검사는 4체형 × 무릎/팔꿈치 × 90/140도 16건의 동일 재질 정점 고리 둘레를 비교한다. 진짜 3차원 부피나 옷 관통 검사를 대체하지 않는다. 고유 체형은 이 수치 검사에서 기본 비율을 사용했다.
- 스크린샷은 실제 WebGL 출력이다. 승인받은 생성형 콘셉트 이미지를 결과 화면으로 사용하지 않는다.

## 실패한 시도와 수정 이유

1. 원본 세부 뼈대를 모든 발 IK 반복에서 다시 순회하자 22명 동작 CPU가 약 16ms까지 늘었다. 필요한 제어 뼈대만 갱신하고 근거리/원거리 뼈대를 분리했다.
2. 접지 종료 때 단순히 잠금을 해제하면 발이 다른 목표 위치로 튀었다. 직전 발 위치에서 이륙하고 도달 가능 범위를 넘기기 전에 이륙하도록 바꿨다.
3. 다리 비율을 늘린 뒤 골반 보정을 매 프레임 기본 자세에 다시 넣으면 달릴수록 몸이 낮아졌다. 기본 골반 높이와 순간 접지 보정을 분리했다.
4. 초기 swing smoothstep은 착지 끝점에서 상대 속도가 0이라 지면 기준으로는 선수 속도만큼 미끄러졌다. 지지 구간의 끝점 속도를 공유하는 보행 곡선과 수직 속도 0인 착지 곡선으로 변경했다.
5. 이전 무릎 보정은 새 다리 비율에서 단면 둘레 손실이 13% 이상이었다. 새 관절 중심의 국소 보정량을 다시 맞췄다. 판정 기준을 느슨하게 바꾸지는 않았다.
6. 착지 속도를 공유하는 5차 곡선은 짧은 공중 구간에서 발 속도 최대값을 더 키웠다. 같은 끝점 위치·속도를 가진 3차 Hermite 곡선으로 바꿔 피크 속도를 줄였다.
7. 실제 경기에서 불가능한 즉시 속도 반전을 넣은 초기 미세 샘플 시험은 해석이 불가능했다. 실제 Match.updatePlayer 한 스텝을 기록해 검사하도록 수정했다.
