# FC-ONLINE-ANALYSIS.md 반영 기록

2026-09-22. 사용자가 제공한 분석 문서의 12–15절을 현재 게임 코드와 대조해 수정했습니다. 수치와 알고리즘은 이 프로젝트의 자체 설계이며 FC Online의 비공개 공식을 재현한 것이 아닙니다.

## 능력치 연결

| 능력치 | 실제 사용하는 계산 |
|---|---|
| pace / acceleration | 최대 질주 속도 / 가속 |
| agility / balance | 방향 전환 속도, 가속 / 제동, 급회전 손실, 킥 자세·압박 오차, 파울 후 회복 |
| control | 드리블 보정 한계, 수신 반경, 첫 터치 감속 |
| passing / longPass | 땅볼·스루 / 크로스·로빙의 속도와 출발 방향 오차 |
| shooting / power | 슛 방향 오차 / 슛 속도 |
| foot / weakFoot | 양발 접촉 후보, 애니메이션 반전 / 반대 발 오차 |
| tackling / strength | 태클 도달 거리 / 몸통 경합 시 상대적 밀림 |
| reflexes / reach | 키퍼 반응 지연, 잡을 수 있는 공 속도 / 선방 범위·높이 |
| height / build | 선수 메시와 논리 접촉 위치, 몸통 충돌 범위 |
| stamina | 최대 속도, 가속, 킥 오차와 피로 회복 |

`attributes.js`에서 계산을 분리했습니다. 같은 초기 상태와 난수로 패스 능력치만 바꾸면 패스가 달라지고, 슈팅 능력치만 바꾸면 패스가 그대로인지 검사합니다. 경기마다 재현 가능한 난수 시드를 사용할 수 있습니다.

## 공 접촉과 입력

- 입력 시각, 수용 시각, 동작 시작, 접촉, 공 출발을 개별 기록합니다. `contacts`에는 최근 80개 접촉만 보관합니다.
- 주발, 공의 측면 위치와 현재 보행 위상을 비교해 킥 발을 고르고 같은 발을 드리블 준비·접촉 판정·애니메이션에서 사용합니다.
- 논리적 접촉 목표를 서버가 결정하고, 실제 킥 사건에서 공 속도와 소리가 발생합니다. 화면의 발은 같은 목표를 IK로 만족시킵니다. 렌더링 FPS를 물리 판정에 사용하지 않습니다.
- 접근하는 공에 한해 최대 0.65초 입력을 보관합니다. 빠른 공은 먼저 트래핑하고 가능한 순간 예약한 킥을 시작합니다. 멀어지는 공이나 먼 공을 원격으로 차지는 않습니다.
- `>=` 시각 통과 검사와 일회성 hit 플래그를 유지합니다. 사거리 밖 공은 발사되지 않습니다.

## 애니메이션·접지·캐릭터

- 관절 보간은 quaternion slerp로 전환했습니다. 임팩트 발 IK는 관절 지연 보간 후 직접 적용합니다.
- 접지 중 발의 월드 좌표를 저장하고 골반 이동 후 두 뼈 IK로 복원합니다. 도달 범위·착지 높이·해제 조건이 있으며 다리를 늘리지 않습니다.
- CMU 달리기 자료의 발 접지 구간을 변환 단계에서 추출합니다. 물리 이동 거리에 따라 보행 위상이 진행되고 해당 위상에서 모션과 접지를 함께 샘플링합니다.
- 출발·감속·방향 전환·뒤로 이동·수비 스텝·첫 터치와 양발 킥을 구분합니다. 원본 모션 캡처는 달리기·킥 두 종류이고 나머지는 절차적 보정·동작입니다.
- 팔·다리를 관절 사이에 연속적인 정점과 가중치를 갖는 SkinnedMesh로 바꿨습니다. 가까운/먼 거리 LOD는 같은 골격을 사용합니다. 원거리 얼굴은 합쳐서 그리고 읽을 수 없는 유니폼 글자는 숨깁니다. 원거리 일반 보행은 접지 위상을 맞춘 모션을 사용하고 근거리 접지 및 모든 킥은 IK를 적용합니다. 얼굴에는 작은 턱 morph와 눈 깜빡임을 추가했습니다.
- 미리보기에서 18개 동작과 왼발/오른발을 선택하고 프레임 단위 자세를 확인할 수 있습니다.

## 화면 시간축

- 오프라인은 고정 물리 스텝 전·후 상태를 accumulator 비율로 보간합니다. 화면용 사본은 물리 상태를 변경하지 않습니다.
- 온라인은 패킷 수신 간격 대신 서버 시뮬레이션 시간을 기준으로 약 65ms 지연 버퍼를 샘플링합니다. 패킷 지터의 시계 보정 폭을 제한하고 표시 시간이 역행하지 않게 했습니다.
- 위치, 회전, 속도, 보행 위상, 액션 elapsed와 hit 상태를 같은 시각에서 보간합니다. 골·진영 변경·큰 위치 재설정은 별도 처리합니다.
- 킥 효과음도 표시하는 접촉 시각에 맞춰 재생합니다. 이는 서버 권위 방식이며 로컬 예측·rollback을 구현했다는 의미는 아닙니다.

## 검증과 남은 범위

고속 낙하 시 지면을 한 스텝 안에 통과하던 경우도 접촉 제약으로 보정했습니다. 공이 잔디 안으로 파고들지 않도록 하고 들어오는 수직 속도에만 반발을 적용합니다.

자동 검사 79개. 추가한 14개 검사는 스탯 분리, 입력 예약, 양발 선택, 접촉 시각, 패킷 지터, 화면 상태 독립성, 발 접지, IK 범위, 스킨 가중치를 다룹니다. `engine-soak-results.json`에는 서로 다른 시드로 전후반 종료까지 진행한 3경기 결과가 있습니다.

실제 브라우저의 정지된 슛 접촉 프레임에서 양발 모두 IK 목표 오차가 0.01cm 미만이고 도달 범위 초과가 없었습니다. 이는 검사한 프레임의 발목 목표 오차이며 전체 경기의 모든 발 미끄러짐·공 표면 오차가 0이라는 뜻은 아닙니다. 미리보기에서 약 40FPS, 52 draw calls를 관찰했습니다. 같은 컴퓨터에서 여러 3D 탭을 동시에 열면 성능이 더 낮아집니다.

F3 진단에 접지/임팩트 오차, 입력→접촉 시간, 프레임 시간 P95를 추가했습니다. 공개 배포본 자유 훈련의 한 슛에서는 발목 목표 오차 약 0.66cm를 관찰했습니다. 실제 경기의 지속 측정값은 상황별로 달라집니다.

남은 자산·제품 범위: 실제 선수 얼굴 스캔, 다양한 상황의 전문 모션 캡처 라이브러리, 모션 매칭 검색 시스템, 정교한 천·머리카락 물리, 상용 수준의 두 선수 상호작용 애니메이션은 갖추지 않았습니다. FC Online과 모든 애니메이션·판정이 동일하다고 주장할 수 없습니다. 판정 관련 기존 한계는 README를 참고하세요.
