# 실행 및 검증 기록

검증일: 2026-09-22. 환경: Windows, Codex 내장 Chromium 브라우저, WebGL2, 자체 포함 Node.js 22.14.0.

이 문서는 초기 빌드 기록입니다. 이후 슛·패스·드리블·소유 보정의 최신 27개 테스트와 자동 경기 기록은 `ASSISTS.md` 및 `assist-soak-results.json`을 확인하세요.

## 환경 확인

- 시작 시 작업 폴더에는 기존 게임 프로젝트·자산이 없었습니다.
- Unreal 설치를 기본 설치 경로에서 찾지 못했고 시스템 PATH에도 Node/npm이 없어, 먼저 만들어 둔 브라우저 3D 구조를 계속 사용했습니다.
- Node 실행 파일을 공식 배포처에서 작업 폴더로 받았습니다. SHA256을 공식 SHASUMS256.txt와 대조했고 일치했습니다.
- 그래픽/CPU의 WMI 하드웨어 조회는 접근 제한으로 실패했습니다. 특정 GPU 모델이나 하드웨어 성능을 추정하지 않았습니다.
- 모든 렌더링·물리 라이브러리는 로컬 vendor 폴더에 포함됩니다. 외부 폰트 의존성도 제거했습니다.

`node --test --experimental-test-isolation=none tests/*.test.mjs`: **16/16 통과**.

6. 일시정지 중 시간과 공 위치 정지.
7. 낙하 후 공 안정화와 지면 유지.
8. 땅볼 감속 및 강약 패스 거리 차이.

13. 패스 시점 오프사이드 스냅샷 유지.
14. 선수 몸에 맞은 공의 반사.
15. 리플레이 스냅샷과 실제 경기 상태 분리.
16. 발이 닿지 않는 공에 대한 킥 거절.

## 자동 경기

최종 `tools/soak.mjs` 실행은 **3경기 모두 fulltime에 도달**했습니다. 게임 시간을 빠르게 계산하는 헤드리스 시뮬레이션이며 3경기를 실시간 화면으로 모두 관람한 테스트는 아닙니다.

| 경기 | 시뮬레이션 시간(중단 포함) | 점수 | 슈팅 | 패스 | 골키퍼 선방 |
|---|---:|---|---|---|---|
| 1 | 약 266초 | 1–1 | 2–1 | 28–24 | 0–1 |
| 2 | 약 259초 | 0–1 | 0–7 | 20–24 | 5–0 |
| 3 | 약 253초 | 0–0 | 2–2 | 25–17 | 2–2 |

전체 시뮬레이션 약 13분. NaN·무한 위치나 경기 진행 정지는 관측되지 않았습니다. 자동 경기 중 킥 준비 후 실패가 여전히 발생합니다. 이는 무조건 발사하지 않는 거리 검사의 결과지만, 더 좋은 접근·첫 터치 애니메이션과 AI 판단이 필요한 부분입니다.

접촉 시 공 중심의 최저 높이는 약 0.073m였습니다. 공 중심이 지면 아래로 관통하지는 않았지만, 이산 충돌 계산으로 순간적인 일부 지면 침투가 발생할 수 있습니다. 정지 후 중심 높이는 공 반지름 0.11m 부근에서 안정화됩니다.

원시 수치는 `soak-results.json`에 저장했습니다.

## 실제 UI/시각 확인

- 메인 메뉴 실제 3D 선수와 경기장 렌더링.
- 자유 훈련 진입, 키보드 K 슛 입력.
- 개발 시나리오에서 이동·드리블, 슈팅, 골 기록 및 재개.
- 골키퍼 선방 이벤트 및 플레이 계속 진행.
- 중계·전술·클로즈업 카메라 변경.
- 종료 직전 QA 시나리오 → 결과 화면 → 다시 도전.
- 일시정지 화면 진입 및 계속 플레이로 재개.
- 팀을 VOLT로, 전후반을 1분으로, 카메라를 중계로 바꾼 후 페이지 재실행. 선택값이 그대로 복원되는 것을 UI에서 확인.
- 테스트 후 기본 팀 APEX, 전후반 2분, 중계 카메라로 복원.
- 키보드 Q 입력 후 조작 선수 변경을 확인했습니다.
- 거리별 선수 재질 배칭을 적용한 뒤 실제 22명 경기 렌더링과 콘솔을 재확인했습니다.
- 확인 시 브라우저 콘솔 오류 목록은 비어 있었습니다.

`screenshots/menu.png`, `screenshots/gameplay.png`, `screenshots/results.png`는 실제 실행 화면입니다. results.png는 정상 결과 UI를 빠르게 검사하기 위해 경기 종료 직전으로 배치한 테스트 장면입니다.

관측 프레임은 대략 31~56 FPS 범위였습니다. 페이지의 순간 FPS 표시를 읽은 결과이며, 표준화된 벤치마크나 안정적인 60 FPS 인증은 아닙니다. 장시간 GPU 메모리 증가와 다양한 하드웨어 비교는 아직 검증하지 않았습니다.

## 아직 실행 검증하지 않은 항목

- 실제 USB/블루투스 게임패드 연결과 진동: 게임패드 입력 코드는 있으나 물리 장치로 검증하지 않았습니다. 진동은 구현하지 않았습니다.
- 모든 수비 각도/속도에서의 킥·태클·다이빙 애니메이션.
- 엄격한 실제 축구 규칙의 모든 예외와 세트피스.
- 별도 PC에서 압축을 풀고 최초 실행하는 과정.
- 사람의 청취를 통한 오디오 믹스 평가.
- 설치형 네이티브 게임 엔진 빌드.
