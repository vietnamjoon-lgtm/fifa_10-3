# 크로스·프리킥·페널티킥 개선

2026-09-24. 이번 변경은 실제 축구에 가까운 궤적과 재개 절차를 만드는 단계이며, 상용 축구 게임과 동일한 구현을 의미하지 않습니다.

## 변경 전과 후

| 상황 | 이전 문제 | 이번 변경 |
|---|---|---|
| 측면 크로스 | 지상 패스용 예상 위치와 거리 비례 높이를 사용 | 박스 안의 온사이드 공격수를 우선하고, 공기저항·회전을 반영한 출발 속도와 높이 계산 |
| 코너킥 | 박스 안 선수 배치와 크로스 대상이 불명확 | 공격수와 마커를 박스에 배치하고 공이 내려오는 높이에 도달하도록 킥 계산 |
| 프리킥 | 근처 선수만 조금 이동하고 수비벽 없음 | 9.15m 이격, 가까운 직접 프리킥에 4인 수비벽, 공격수의 벽 접근 제한 |
| 프리킥 조작 | 일반 슈팅의 자동 코너 조준을 사용 | 골문 좌우·높이 직접 조준, 7종 궤적, 골문 조준점과 전용 카메라 |
| 페널티킥 | 일반 경기 위치와 슈팅을 사용 | 11m 지점, 골키퍼 골라인, 나머지 선수는 박스·아크 밖이며 공 뒤에 배치 |
| 킥 준비 | 대기 중 공 터치와 8초 자동 재개 | 접촉 전 공 정지, 사람 30초·AI 2초 준비, 다른 선수의 킥·전환 차단 |
| 재개 판정 | 차는 선수의 연속 접촉 등 누락 | 다른 선수 접촉 전 두 번 터치 금지, PK 후방 킥 간접 프리킥, PK 실행 중 전후반 종료 유예 |

공중볼 계산은 발에 닿는 순간 한 번 수행합니다. 이후 공은 상대의 차단, 몸·골대 충돌, 중력과 회전에 따라 움직이며 목표 선수를 추적하지 않습니다. 패스 오차와 수동 크로스 설정도 유지합니다. 기존 발 접촉·헤딩·첫 터치 동작을 사용하며 공중볼 선입력 허용 범위를 넓혔습니다.

기본 키 배치에서 프리킥·PK는 ←→ 좌우, ↑↓ 높이, D 누르고 놓기로 실행합니다. 프리킥 1~7은 궤적 선택입니다. 빨간 조준점은 골문 밖을 뜻합니다. 조준점은 보장된 도착점이 아니며 과한 힘, 선수 정확도, 무회전 변화, 충돌에 따라 결과가 달라집니다.

## 검증

- 전체 검사 203개 통과: `setpiece-tests.txt`.
- 실제 Cannon 공으로 12/25/40m 크로스, 양발, 낮은 크로스의 도달 거리·높이·하강 여부를 검사했습니다.
- 양 팀·양 전반 방향의 수비벽 거리, PK 배치, 정지 공, 조준 입력, 코너킥 접촉, 후방 PK와 두 번 터치 판정을 검사했습니다.
- 친구 대전 두 좌석의 조준 입력 분리와 스냅샷 전달을 검사했습니다. 이번 코드의 운영 서버 연결 검사는 별도입니다.
- 자동 경기 3회 모두 전후반·종료까지 진행, 비정상 좌표 없음: `setpiece-soak.json`.
- 웹 빌드 통과. 별도 로컬 브라우저에서 프리킥·PK·코너킥 장면과 조준·킥 실행을 확인했습니다. 사용자 선수·사진 데이터는 변경하지 않았습니다.

## 규칙 근거와 남은 범위

[IFAB Law 13 — Free Kicks](https://www.theifab.com/laws/latest/free-kicks/)와 [Law 14 — The Penalty Kick](https://www.theifab.com/laws/latest/the-penalty-kick/)의 공 정지, 거리, 위치, 재접촉과 PK 진행 방향을 참고했습니다.

아직 수비벽 점프, 자유로운 수비벽 편집, PK 골키퍼의 수동 좌우 이동·다이빙, 침범에 따른 모든 재시도 분기, 우발적인 PK 더블 터치 예외, 연장된 전후반에서 골키퍼 굴절 후 득점 처리 전체, 공중 경합 전용 애니메이션은 완전 구현하지 않았습니다. 준비 중 선수 배치는 고정되므로 실제 경기의 모든 움직임을 재현하지 않습니다. 골키퍼의 전체 선방 수치는 이번에 임의로 재조정하지 않았습니다.
