# fifa_10-3 · PROJECT TOUCHLINE

[GitHub Pages에서 게임 시작](https://vietnamjoon-lgtm.github.io/fifa_10-3/) · [기존 Vercel 주소](https://project-touchline-three.vercel.app/). main에 합친 변경은 Pages에 자동 배포됩니다. [Pages 운영 안내](reports/GITHUB-PAGES.md).

브라우저에서 실행하는 싱글 플레이와 온라인 친구 대전을 지원하는 11대11 3D 축구 게임 프로토타입입니다. 독자적인 팀·선수·경기장과 물리 시뮬레이션을 사용합니다. FC Online의 공개 조작 가이드를 참고했으며, 비공개 판정 수치나 상용 선수 모델을 복제한 제품은 아닙니다.

## 실행

Windows 배포 ZIP에서는 PLAY.cmd를 더블클릭해 실행합니다. GitHub에서 받은 소스는 Node.js 22 이상 설치 후 `node server.mjs`를 실행하고 [로컬 게임](http://localhost:4173/)을 엽니다. Three.js/Cannon-es는 저장소에 포함돼 있습니다. Chrome/Edge의 WebGL2가 필요합니다. 메인 메뉴에서 킥오프, 친구와 1대1, 자유 훈련을 선택하세요. 온라인 접속과 추천 조작 설정은 [친구 대전 안내](reports/ONLINE-PLAY.md)를 참고하세요.

## 조작

기본값은 온라인 축구 키 배치입니다. 매치 센터에서 기존 WASD/J/K 방식이나 전략 수비로 변경할 수 있습니다. 경기 중 H로 전체 조작표를 엽니다.

| 동작 | 키 |
|---|---|
| 이동 / 질주 | 방향키 / E |
| 패스 / 스루 / 크로스 | S / W / A |
| 슛 | D를 누르고 놓기 |
| 감아차기 / 칩슛 / 낮은 슛 | Z+D / Q+D / D 놓고 D |
| 로빙 스루 / 강한 스루 | Q+W / Z+W |
| 패스 후 침투 / 강한 패스 | Q+S / Z+S |
| 얼리 / 바운싱 크로스 | Q+A / Z+A |
| 땅볼 / 낮은 크로스 | A 두 번 / 세 번 |
| 페이크 / 동작 취소 | D 또는 A 후 S / E+C |
| 공 보호 / 짧은 터치 / 녹온 | C / Space / Ctrl+방향키 |
| 동료 침투 / 지원 | Q / Z |
| 기본 수비: 변경 / 자동 수비 / 협력 | S / D 유지 / Q 유지 |
| 전략 수비: 변경 / 압박 / 자동 수비 / 협력 | Q / S 유지 / D 유지 / Z 유지 |
| 슬라이딩 / 견제 / 키퍼 돌진 | A / C / W 유지 |
| 키퍼가 잡은 공: 패스 / 킥 / 놓기 | S / A·D / W |
| 카메라 / 일시정지 / 진단 | F2 / Esc / F3 |

수비 시 D를 누르고 있으면 공을 가진 상대에게 접근해 수비 자세를 취하고, 공에 닿을 수 있는 거리에서 태클합니다. 방향키를 누르면 직접 이동을 우선하며 D를 놓으면 해제됩니다. 공격 시 D는 기존대로 슈팅입니다. 개인기는 Shift+1~7, 프리킥 궤적은 1~7로 선택합니다.

연속 입력은 공 접촉 전에 해야 합니다. 공격·수비에 따라 같은 키의 역할이 바뀝니다. 골킥·코너킥·프리킥·페널티킥은 재개 후 직접 차며, 스로인은 S/A/W로 던집니다. 사람이 차는 재개는 최대 30초, AI는 2초 뒤 자동 재개합니다. 프리킥·페널티킥에서는 좌우로 골문 가로 조준, 위아래로 높이를 정하고 D를 누른 뒤 놓아 찹니다. 골문 밖 조준점은 빨간색으로 표시합니다. [크로스·세트피스 개선과 검증](reports/CROSSES-SETPIECES.md).

표준 게임패드 매핑: LS 이동, RT 질주, A 패스, B 슛, X 크로스, Y 스루, LB 조합/변경, RB 감아차기/협력 수비. 실제 장치를 연결한 검증은 아직 하지 않았습니다.

사진을 선택하면 눈매·눈썹·입술·턱선을 분석해 입체 얼굴을 조정합니다. 기존 얼굴은 편집에서 다시 분석하세요. 최근 얼굴·동작·골키퍼 수정과 비교 검사는 [개선 기록](reports/FACE-MOTION-KEEPER-V2.md)에 있습니다.

## 플레이와 판정

- 105×68m 경기장, 22명 선수, 4-3-3 AI, 전후반 방향 전환, 득점·리플레이·결과 화면.
- Cannon-es 강체 공, 중력·공기저항·구름 마찰·회전, 선수·골대 충돌, 120Hz 시뮬레이션과 추가 물리 서브스텝.
- 골문 안쪽 슛 조준, 방향 전환 드리블과 첫 터치 보정. 기본 패스와 크로스는 수신자 위치를 향하고 비행 중 공의 수평 속도를 보정합니다. 받는 선수를 공 쪽으로 자동 이동시키지 않으며, 중력·바운스·가로채기·경기 판정은 유지됩니다. 공 추적을 끄거나 수동 패스를 선택하면 기존 물리 궤적을 사용합니다. [패스 개선 기록](reports/PASS-TO-FEET.md).
- 볼 선접촉/몸 선접촉 태클, 페널티 지역 파울, 경고·누적 경고 퇴장, 심한 태클 퇴장, 짧은 어드밴티지와 회수, 추가 시간.
- 패스 시점 오프사이드, 세트피스 직접 수신 예외, 굴절과 소유 구분, 스로인·간접 프리킥 직접 득점 제한, 키퍼 백패스 손 처리 제한.
- 짧은 볼 터치·공 보호·기본 페인트·협력 수비 게이지·골키퍼 돌진과 배급.

분석 문서 반영 내역과 능력치 소비표는 [엔진 개선 기록](reports/ENGINE-FIXES.md)에 있습니다.

매치 센터의 **플레이 감각 · 파울 세부 설정**에서 출발·멈춤·방향 전환, 공 굴림·반발, 첫 터치와 파울 엄격도를 조절할 수 있습니다. 온라인은 방장의 설정을 두 팀에 똑같이 적용합니다. 이번 충돌·태클·오프사이드·보행 수정과 검증 범위는 [이동·물리·판정 기록](reports/GAMEPLAY-OVERHAUL.md)에 정리했습니다.

출처, 구현 범위와 한계는 [조작·판정 기록](reports/ONLINE-CONTROLS.md), 이전 보정 수치는 [보정 기록](reports/ASSISTS.md)에 있습니다.

## 검증

명령: node --test --experimental-test-isolation=none tests/*.test.mjs

2026-09-24 기준 자동 검사 183개 통과. 이번 물리·판정 변경의 자동 경기 3회가 모두 전후반과 종료까지 진행했으며 비정상 좌표는 없었습니다. 기록은 reports/gameplay-overhaul-soak.json입니다. 최신 검증은 reports/DEPLOYMENT.md에 있습니다. 여러 3D 탭을 동시에 켜면 성능이 낮아질 수 있으며 60 FPS를 보장하지 않습니다. 느리면 PERFORMANCE와 렌더 해상도 80%를 사용하세요.

로컬 ?qa=1에서는 개발용 장면 버튼을 표시합니다. 공개 배포 빌드에서는 이 기능을 제외합니다.

## 웹 배포와 Windows 묶음

웹 빌드: node tools/build-web.mjs

Vercel CLI 계정 인증 후 배포: vercel deploy --prebuilt --prod

웹 빌드는 .vercel/output/static에 게임 실행 파일만 복사합니다. 인증 정보, Node 실행 파일, 테스트, 보고서는 업로드하지 않습니다. Windows ZIP은 BUILD.ps1로 생성합니다. 압축을 푼 뒤 PLAY.cmd로 실행하세요. 웹 배포와 달리 ZIP에는 오프라인 실행용 Node가 포함됩니다.

## 현재 한계

- 선수는 MakeHuman CC0 인체를 게임 관절에 맞춘 3D 메시와 비율 조절형 3D 얼굴입니다. 달리기·킥은 CMU 모션 캡처를 적용했으며 상용 스캔·실제 선수 얼굴·실제 천 물리는 포함하지 않습니다.
- 판정과 조작 보정은 자체 모델입니다. FC Online과 동일한 충돌 판정·입력 지연·온라인 보정·전체 개인기 수치를 보장하지 않습니다.
- 헤딩·발리·스로인·슬라이딩은 단순화된 동작입니다. 세트피스 수비벽 편집, 핸드볼, VAR, 모든 오프사이드 관여 예외, 연장전·승부차기·선수 교체는 미구현입니다.
- AI와 골키퍼는 절차적인 예측을 사용하며 실전 완성도 개선이 필요합니다. 친구 대전은 지원하지만 공개 매칭·커리어·해설은 없습니다.

## 코드

src/match.js는 경기 상태, input.js·commands.js는 조작, referee.js·rules.js는 판정, assists.js는 플레이 보정, physics.js·contacts.js는 공과 충돌을 담당합니다. 선수 모델·경기장·렌더링은 player.js·stadium.js·main.js에 있습니다.

## 자산과 라이선스

몸·머리의 바탕은 MakeHuman CC0 데이터이며 팀·경기장·유니폼·관중·UI 및 특수 동작은 자체 제작했습니다. 얼굴 랜드마크 분석은 MediaPipe Tasks Vision(Apache-2.0)을 로컬에서 실행합니다. 자세한 출처는 licenses/HUMAN-ASSETS.md에 있습니다. 오디오는 Web Audio 합성입니다. Three.js 0.180.0과 Cannon-es 0.20.0은 MIT 라이선스이며 licenses에 원문이 있습니다. Windows 실행용 Node.js 22.14.0은 공식 배포본 체크섬으로 검증했습니다.


선수 편집과 최신 애니메이션 변경: reports/RESEARCH-IMPLEMENTATION.md. 메인 메뉴에서 선수 · 팀 편집, 자료 · 동작 목록을 열 수 있습니다.

## 3D 페이스온과 동작

앞모습 사진에서 눈·코·입·턱 비율을 읽어 3D 얼굴 형태로 적용할 수 있습니다. 옆·뒤 사진은 수동 조정용 참고 자료로 사용합니다. 눈 깜빡임·시선·입 움직임, 14개 얼굴 조절 값, 선수별 세리머니 선택을 지원합니다. 사용법과 한계는 [얼굴 안내](reports/FACE-ON.md), 영상 200개와의 대응 내역은 [영상 반영 기록](reports/VIDEO-APPLICATIONS.json), 이번 변경은 [동작 개선 기록](reports/HUMAN-MOTION-UPDATE.md)에 있습니다.

## 능력치와 공 받기 보정

선수 능력치는 100점 만점의 정수입니다. 패스 0.81은 81점으로 표시하며 종합 점수·6개 항목 요약·색상 막대로 비교할 수 있습니다. 키는 cm, 체중은 kg이며 각각 소수 첫째 자리까지 편집합니다. 신체 상세 조절에서 어깨·허리·팔다리 등 16개 비율을 3D 미리보기로 조절합니다. 기존 저장 파일은 계속 사용할 수 있습니다. [체형 편집 안내](reports/BODY-CUSTOMIZATION.md).

빈 공 자동 접근은 기본으로 켜져 있습니다. 패스 정확도 100 설정에서는 공이 수신자를 따라가며 수신자를 공 쪽으로 자동 이동시키지 않습니다. 받기 이동 지원은 궤적 추적을 끈 경우 적용합니다. 골키퍼는 이전 약한 버전과 최초 버전의 중간으로 조정했습니다. [최신 패스·골키퍼 검사](reports/GUIDED-PASS-AND-KEEPER.md).
