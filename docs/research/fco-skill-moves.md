# FC 온라인 개인기·조작키 (공식 가이드 기준)

출처: 넥슨 FC 온라인 공식 가이드 「게임 조작법(키맵/기본수비/전략수비/개인기)」, 2022-09-22 게시, 2026-09-25 확인. https://m.fconline.nexon.com/news/guide/view?n4articlesn=160

방향은 공식 표처럼 **왼쪽에서 오른쪽으로 공격할 때 기준**이다. → 앞, ← 뒤, ↑ 선수 왼쪽, ↓ 선수 오른쪽이다. 같은 입력이라도 선수 개인기 별 수에 따라 다른 기술이 나간다.

## 무브먼트 조작 (기본수비 표에서 발췌)

| 기술 | 키보드 | 패드 |
|---|---|---|
| 공 멈추고 골대 보기 | Q + no direction | LB + no direction |
| 선수 이동 | 방향키 | LS |
| 공 지키기/견제 | C + direction | LT + direction |
| 페이스 업 드리블 | C + E | LT + RT |
| 개인기 발동 | SHIFT + 방향키 | RS |
| 전력 질주 | E + direction | RT + direction |
| 공 멈추기 | E + no direction | RT + no direction |
| 퍼스트 터치/녹온 | CTRL + 방향키 | RT + RS + direction |
| 노 터치 작은 페인팅 | Q | LB |
| 노 터치 큰 페인팅 | Q + E | LB + RT |
| 슛하는 척하기 | D 후 S + direction | B 후 A + direction |
| 패스하는 척하기 | A 후 S + direction | X 후 A + direction |

전체 기본 조작 표(패스·슛·수비·골키퍼·세트피스)는 같은 공식 페이지에 있다.
