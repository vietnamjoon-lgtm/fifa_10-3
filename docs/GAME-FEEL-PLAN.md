# 게임다운 게임 만들기 — 전체 손보기 계획서

작성 2026-09-28 · 브랜치 `work/game-feel` · 측정 도구 `tools/feel/`

이 문서는 "기능은 있지만 하기 어렵고 FC 온라인과 느낌이 다르다"는 문제를 **측정 가능한 항목**으로 쪼개고,
하나씩 고친 뒤 같은 측정으로 전후를 비교하기 위한 틀입니다. FC 온라인의 비공개 수치는 알 수 없으므로,
아래의 "FC 기준"은 공개 조작 가이드와 일반적인 플레이 경험에서 나온 **추정 목표**이지 공식 값이 아닙니다.
결과 보고서에는 측정값과 한계만 적고 "FC와 같다"고 주장하지 않습니다.

## 0. "재밌다"를 무엇으로 재는가

재미를 직접 잴 수는 없으므로 재미를 망치는 원인을 잽니다.

| 축 | 망치는 원인 | 잴 것 |
|---|---|---|
| 반응 | 키를 눌렀는데 안 나감, 늦게 나감 | 입력→공 출발 지연(p50/p90), 무시된 입력 비율 |
| 조작 | 공이 발에서 멀어짐, 방향 전환이 둔함, 이유 없이 뺏김 | 드리블 공 간격, 방향 전환 시간, 드리블당 뺏김 |
| 수비 | 막을 방법이 없음 | 1대1 D 유지 수비 성공률, 경기당 되찾기 수 |
| 득점 | 너무 쉽거나(허무) 너무 어려움(답답) | 슛당 골, 유효 슈팅 비율, 거리별 선방률 |
| 상대 | AI가 바보 같거나 사기 같음 | AI 패스 성공률, 턴오버/분, 난이도별 승률 차이 |
| 흐름 | 멈춘 시간이 길고 할 일이 없음 | 경기 중 멈춘 시간 비율, 재개까지 걸린 시간 |
| 화면 | 무엇을 해야 할지 모름 | 파워 게이지, 전환 표시, 상황별 키 안내 유무(체크리스트) |

### 측정 도구 (이번 작업에서 추가)

- `tools/feel/match-stats.mjs` — AI 대 AI 경기 통계: 골·슛·유효슈팅·패스 성공·가로채기·턴오버·멈춘 시간·재개 종류.
- `tools/feel/human-bot.mjs` — **가상 키보드 플레이어**가 실제 `Input` 클래스(8방향 방향키, S/W/A/D, E 질주,
  D 유지 수비, S 선수 변경)로 사용자 팀을 조작해 AI와 경기합니다. 사람이 느끼는 어려움을 숫자로 봅니다.
  - 공격: 골문 쪽으로 드리블, 앞 4 m에 수비가 없으면 질주, 21 m 안에서 먼 포스트로 D 0.38초 충전 슛,
    수비가 2.6 m 안이면 빈 동료에게 S(전방 공격수면 W), 3.5초 넘게 끌면 전진 패스.
  - 수비: 공 가진 상대가 6 m 안이면 D 유지, 멀면 방향키+E로 추격, 더 가까운 동료가 있으면 S로 변경.
  - 반응 주기 0.12초. 사람보다 단순하지만 매번 같은 방식이라 전후 비교에 씁니다.
- `tools/feel/drills.mjs` — 고립 장면 측정: 가속, 공 몰고 방향 전환, 드리블 간격, 입력 지연, 패스 받기,
  1대1 수비(D 유지 / D+E / 직접 추격+D), 거리별 골키퍼 선방.

## 2. 작업 순서와 이유

가장 크게 재미를 망치는 순서로 고칩니다. 각 단계는 **(문제 → 원인 코드 → 바꿀 것 → 목표 수치 → 검증)** 으로 적고,
끝나면 같은 도구로 전후 표를 남깁니다. 한 단계가 목표에 못 미치면 다음 단계로 넘어가기 전에 이유를 적습니다.

### 단계 1 — 수비가 되게 하기 (가장 큼)

**문제**: 1대1 성공 0/20, 경기당 되찾기 1.5회.

| # | 바꿀 것 | 파일(담당) | 목표 |
|---|---|---|---|
| 1-1 | D 유지(압박) 이동: 공 가진 상대 앞 골문 쪽 1.2~1.5 m 지점으로, 상대 속도+여유만큼 따라감. 3 m보다 멀면 자동 질주로 붙음, E를 누르면 항상 질주 | auto-defence.js(03), match.js move(04) | D 유지로 상대 질주를 따라감 |
| 1-2 | 붙은 뒤 게걸음(jockey): 상대가 느리면 옆걸음, 상대가 방향을 틀면 반응 시간 뒤 따라 틂 | auto-defence.js, match.js | |
| 1-3 | 공 가지고 질주 속도 = 빈 몸 질주의 0.90~0.94(드리블·볼컨트롤 능력치) | match.js move(04), attributes.js(03) | 수비수가 따라잡을 여지 |
| 1-4 | 자동 태클: 공이 발에서 떨어진 순간(간격 > 0.55 m), 상대가 방향을 트는 순간, 1.3 m 안이면 태클 | auto-defence.js | |
| 1-5 | D 탭(스탠딩 태클): 1.6 m 안이면 공 쪽으로 뻗는 태클. 성공 확률은 태클 능력치 대 드리블·볼보호, 뒤·옆에서는 파울 위험 | commands.js(03), referee.js resolveTackle(04) | |
| 1-6 | S 선수 변경: 공의 0.35초 뒤 위치에 가장 가깝고 골문 쪽에 있는 선수 우선 | match.js switchPlayer | 변경 1회당 쓸모 있는 선수 |
| 1-7 | 1대1 드릴에 양 팀 방향과 AI 난이도별 결과 추가 | tools/feel/drills.mjs | |

목표: 1대1 D 유지 **성공 35~55%**, 돌파 ≤ 45%, 파울 ≤ 10%. 가상 플레이어 되찾기 **경기당 ≥ 3회**, 실점 감소.
너무 쉬우면(성공 > 70%) 드리블이 무의미해지므로 상한도 봅니다.

**문제**: 패스 입력 약 10%가 무시됨, p90 지연 0.43초.

| # | 바꿀 것 | 파일 | 목표 |
