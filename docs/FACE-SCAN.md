# 3D 스캔 얼굴 넣기 (친구용 안내)

아이폰으로 얼굴을 3D 스캔해서 게임 선수 머리에 거의 그대로 옮기는 방법입니다. 순서는 다섯 단계입니다.

1. 앱 고르기
2. 스캔하기
3. 파일 내보내기
4. 맥에서 얼굴 팩으로 바꾸기
5. 게임에서 불러오기

> 스캔과 얼굴 팩은 내 얼굴 데이터입니다. 저장소(GitHub)에 올리지 마세요. `scans/` 폴더, `*.tlface`, `*.obj` 같은 파일은 git이 무시하도록 설정돼 있습니다. 그래도 커밋 전에 `git status`로 한 번 더 확인하세요.

## 1. 앱 고르기

**텍스처(색)가 있는 3D 파일을 OBJ나 GLB로 내보낼 수 있는 앱**이면 됩니다.

| 앱 | 방식 | 참고 |
|---|---|---|
| OpticALLY | 앞면 트루뎁스 카메라(Face ID 기종) | 얼굴 전용이라 가장 쉽습니다. OBJ 내보내기 |
| Heges | 트루뎁스 또는 라이다 | 무료 기능으로 스캔이 됩니다. 내보내기 형식은 앱 안내를 확인하세요 |
| KIRI Engine | 사진 여러 장(사진측량) | 라이다가 없는 기종도 됩니다. 처리 시간이 걸립니다 |

위 표는 이 문서를 쓴 시점의 일반적인 설명입니다. 이 프로젝트에서 각 앱으로 실제로 찍어 본 것은 아닙니다. 앱 버전에 따라 무료 범위와 내보내기 형식이 다를 수 있습니다.

## 2. 스캔 요령

- **밝은 곳**: 창가나 밝은 실내에서 찍고, 얼굴에 강한 그림자가 지지 않게 합니다. 역광은 피하세요. 스캔 색이 그대로 게임 텍스처가 됩니다.
- **가만히**: 찍는 동안 머리를 움직이지 않습니다. 친구가 폰을 들고 천천히 얼굴 주위를 돌면 가장 좋습니다.
- **머리카락 정리**: 이마와 귀를 가리지 않게 넘깁니다. 모자·안경·마스크는 벗습니다. 게임은 이마 위쪽과 뒤통수에 게임 머리 모양을 그대로 씁니다.
- **무표정**: 입을 다물고 눈을 뜬 편안한 표정으로 찍습니다. 웃거나 입을 벌리면 그 표정이 얼굴 모양으로 굳고, 게임 표정(깜빡임·소리치기)과 겹쳐 어색해집니다.
- 목과 어깨가 조금 찍혀도 괜찮습니다. 변환 도구가 목 아래와 떠 있는 조각을 잘라냅니다.

## 3. 파일 내보내기

- 앱에서 **OBJ**(텍스처 PNG/JPG와 `.mtl` 파일이 같이 나옴) 또는 **GLB**로 내보냅니다.
- OBJ라면 `.obj`, `.mtl`, 텍스처 이미지를 **같은 폴더**에 둡니다. `.mtl`이 이미지 파일 이름을 가리키기 때문입니다.
- 에어드롭 등으로 맥에 옮기고, 저장소의 `scans/` 폴더(git이 무시함)나 저장소 밖 폴더에 넣습니다.

## 4. 맥에서 얼굴 팩으로 바꾸기

### 처음 한 번 준비

1. [Blender](https://www.blender.org/)를 설치합니다(4.x 이상, 5.1에서 확인). 기본 위치가 아니면 `BLENDER=/경로/Blender`를 앞에 붙여 실행합니다.
2. Node.js 22 이상(게임 실행에 쓰는 것과 같음)과 python3을 준비합니다. python3에는 Pillow와 numpy가 필요합니다.
3. 얼굴 점 검출용 MediaPipe 가상환경을 만듭니다. 저장소 폴더에서 아래를 실행합니다.

```text
python3 -m venv tools/human/rocketbox/.cache/venv
tools/human/rocketbox/.cache/venv/bin/pip install -r tools/human/rocketbox/requirements.txt
```

### 변환 (명령 하나)

```text
node tools/human/scan/make-face-pack.mjs scans/내얼굴.obj --avatar asian_01
```

- `--avatar`: 스캔을 붙일 게임 머리입니다. 머리 모양과 귀·뒤통수는 이 머리를 그대로 씁니다.

  | 값 | 머리 |
  |---|---|
  | `asian_01` (기본값) | 동양 A, 옆가르마 |
  | `asian_02` | 동양 B, 앞머리 |
  | `male_02` | 서양 A |
  | `male_03` | 서양 B, 레게 머리 |

- `--out 파일.tlface`: 결과 파일 위치입니다. 생략하면 스캔 옆에 `내얼굴.tlface`로 만듭니다.
- 걸리는 시간은 가상 스캔 기준 약 20초입니다.

도구가 하는 일:

1. 스캔에서 가장 큰 덩어리만 남기고(떠 있는 조각 제거), 24방향으로 렌더링해서 MediaPipe로 가장 정면인 얼굴을 찾습니다.
2. 얼굴 468점을 스캔 표면에 찍어, 게임 머리의 같은 468점(`assets/human/rocketbox/face-landmarks-3d.json`)에 크기·회전·위치를 맞춥니다. 게임 보정과 같은 정면 카메라로 한 번 더 맞춥니다.
3. 게임 머리 정점을 랜드마크를 따라 움직인 뒤, 얼굴 부분만 가장 가까운 스캔 표면에 붙입니다. 뒤통수·두피·목 이음새는 움직이지 않습니다.
4. 스캔 색을 게임 머리 텍스처 배치(UV)로 굽고, 가장자리 밝기를 게임 머리에 맞춰 섞습니다.
5. 결과를 얼굴 팩(`.tlface`) 한 파일로 저장합니다.

얼굴 팩 파일 한 개에 들어 있는 것:

- 게임 머리 id
- 머리·머리카락 정점 이동값(정점당 3바이트, 0.25 mm 단위, 축마다 ±31.75 mm)
- 머리 텍스처(1024 px JPEG)
- 온라인용 작은 텍스처(256 px)
- 얼굴 피부색

파일 크기 상한은 56만 자(약 550 KB)입니다. 가상 스캔으로 만든 팩은 214 KB였습니다.

화면에 나오는 숫자 읽는 법:

- `얼굴 검출: 렌더 24장 중 N장`: 0장이면 얼굴을 못 찾은 것입니다. 텍스처가 없거나 얼굴이 너무 어둡지 않은지 확인하세요.
- `정면 재정렬 … 오차 N mm`: 내 얼굴과 게임 머리의 모양 차이도 들어가므로 0이 아닙니다(가상 스캔 8.9 mm). 30 mm 이상이면 정렬이 틀렸을 수 있습니다.
- `머리 정점 이동: 최대 N mm`: 가상 스캔은 15.3 mm였습니다.

## 5. 게임에서 불러오기

1. 게임을 열고 **선수 편집**에서 선수를 고릅니다.
2. 얼굴 카드의 **3D 스캔 얼굴 불러오기**를 누르고 `.tlface` 파일을 고릅니다.
3. 그 선수의 얼굴 바탕이 팩의 머리로 바뀌고, 피부색이 스캔 얼굴색으로 맞춰집니다. 이 브라우저의 얼굴 저장소(IndexedDB)에 저장되며, 다음 경기와 메뉴부터 적용됩니다.
4. **선수 카드 내보내기**를 하면 스캔 얼굴도 같이 들어갑니다. 친구가 카드를 불러오면 그 친구 브라우저에도 저장됩니다.
5. **온라인 친구 대전**에서는 작은 텍스처(256 px)와 이동값만 보냅니다. 방 요청 크기 제한을 넘으면 뒤 선수부터 스캔 얼굴이 빠지고, 그 선수는 기본 머리로 보입니다.

## 한계

- 이 기능은 Rocketbox 성인 머리(`Male_Adult_08`)로 만든 **가상 스캔**으로만 확인했습니다. 실제 사람 스캔이나 위 앱들의 실제 출력으로는 시험하지 않았습니다.
- 게임 머리 정점(약 1,650개)을 스캔 표면에 붙이는 방식이라, 스캔보다 훨씬 거칩니다. 잔주름이나 속눈썹 같은 세부는 텍스처로만 남습니다.
- 머리카락·귀·뒤통수는 고른 게임 머리 그대로입니다. 머리 모양은 편집기의 머리 모양으로 고르세요.
- 게임 머리의 노멀맵(주름·모공 요철)은 원래 머리 기준 그대로라서, 스캔 얼굴과 세부 요철이 조금 어긋날 수 있습니다.
- 표정 모프는 원래 머리 기준 이동량이라, 스캔 얼굴에서 입·눈이 움직이는 모양이 원래 머리와 같습니다.
- 스캔 앱의 색 보정과 조명이 텍스처에 그대로 남습니다. 도구가 가장자리 밝기만 맞춥니다.
